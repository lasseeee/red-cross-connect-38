# Red Cross Connect (38)

create a app to connect volunteers and participants in the red cross. we want to visualize on a map where the participants are located (roughly, like airbnb apartments) and volunteers (we have exact address). we by filter by travel time and distance, by car. public transport and bike.  employees at the red cross use a lot of time to connect volunteers with participants, we want to make this more efficient. it should live as a web app.
